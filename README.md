## 📖 Sobre o Projeto
Este projeto consiste no desenvolvimento de um sistema informatizado para substituir os registos manuais de um hospital de médio porte. O objetivo principal é centralizar e gerir todas as informações relacionadas com os atendimentos, melhorando a organização dos dados, reduzindo erros operacionais e fornecendo informações fiáveis para o apoio às atividades administrativas e médicas.

## ⚙️ Funcionalidades (Escopo)
De acordo com os requisitos do sistema, a aplicação permite:
- 👥 Gestão de pacientes e profissionais de saúde.
- 📅 Agendamento e controlo de consultas (evitando conflitos de horário).
- 🛏️ Gestão de quartos hospitalares e controlo de internações.
- 📋 Registo e consulta do histórico médico de atendimentos dos pacientes.

## 🚀 Tecnologias Utilizadas
**Front-end (Sprint 1):**
- HTML5 & CSS3 (Variáveis CSS, Flexbox, Grid)
- Phosphor Icons (Ícones)

**Back-end & Infraestrutura (Próximas Sprints):**
- **Linguagem/Framework:** Java com Spring Boot (API REST).
- **Arquitetura:** Camadas (Controller, Service, Repository, Model) utilizando POO.
- **Base de Dados:** Relacional (MySQL/PostgreSQL) ou Não-Relacional (MongoDB).

## 📚 Documentação de Engenharia
Todo o planeamento estrutural do sistema encontra-se na pasta `docs/`:
- **Diagrama de Classes (UML):** Modelação orientada a objetos da arquitetura do sistema.
