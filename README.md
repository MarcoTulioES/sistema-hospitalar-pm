# 🏥 Sistema de Informação Hospitalar (HospManager)

> Trabalho Prático desenvolvido para a disciplina de Programação Modular do Bacharelato em Engenharia de Software da PUC Minas[cite: 7].

## 📖 Sobre o Projeto
Este projeto consiste no desenvolvimento de um sistema informatizado para substituir os registos manuais de um hospital de médio porte[cite: 7]. O objetivo principal é centralizar e gerir todas as informações relacionadas com os atendimentos, melhorando a organização dos dados, reduzindo erros operacionais e fornecendo informações fiáveis para o apoio às atividades administrativas e médicas[cite: 7].

## ⚙️ Funcionalidades (Escopo)
De acordo com os requisitos do sistema, a aplicação permite:
- 👥 Gestão de pacientes e profissionais de saúde[cite: 8].
- 📅 Agendamento e controlo de consultas (evitando conflitos de horário)[cite: 8].
- 🛏️ Gestão de quartos hospitalares e controlo de internações[cite: 8].
- 📋 Registo e consulta do histórico médico de atendimentos dos pacientes[cite: 8].

## 🚀 Tecnologias Utilizadas
**Front-end (Sprint 1):**
* HTML5
* CSS3 (Variáveis CSS, Flexbox, Grid)
* Phosphor Icons (Ícones)

**Back-end & Infraestrutura (Próximas Sprints):**
* **Linguagem/Framework:** Java com Spring Boot (API REST)[cite: 7].
* **Arquitetura:** Camadas (Controller, Service, Repository, Model) utilizando POO[cite: 7].
* **Base de Dados:** Relacional (MySQL/PostgreSQL) ou Não-Relacional (MongoDB)[cite: 7].
